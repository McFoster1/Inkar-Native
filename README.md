# Inkar (native)

The native Kotlin version of Inkar, built with Jetpack Compose. Work in progress.

During development it installs as **Inkar (dev)** with the app ID `com.mcfoster.inkar.dev`, next to the real Inkar.

## Build

Go to **Actions > Build Kotlin APK > Run workflow**, enter a version (for example `0.1.0`) and run it. The APK appears under **Releases** after a few minutes.
